# 설계 결정: 홈 화면 목표 달성률 기준 변경

## 결정일
2026-05-06

## 질문
와이어프레임의 "월 ¥30,000 목표"는 배당의 월별 불균형(6월, 12월 집중)과 맞지 않습니다. 어떤 기준의 목표로 변경할 것인가?

## 결정
**연간 세후 배당 목표로 변경하고, "올해 예상 세후 배당" 카드에 통합하여 표시합니다.**

### 변경 전 (와이어프레임)
```text
목표 달성률
월 ¥30,000 목표
현재 ¥28,400 / 94%
```

### 변경 후
```text
올해 예상 세후 배당
¥384,000
세전 ¥480,000 / 예상 세금 ¥96,000
─────────────────────────
연간 목표 ¥400,000 대비 96%
[██████████░]
```

### 설정 화면 추가
- 표시 설정 아래에 **"연간 배당 목표 (円)"** 숫자 입력 필드 추가
- NULL(빈 값)이면 목표 UI를 숨기고, "목표를 설정해보세요" CTA 표시

### DB 스키마
- `users` 테이블에 `annual_dividend_goal` (INTEGER, DEFAULT NULL) 추가

## 근거
- 월 목표는 배당이 집중되는 월(6월, 12월)에는 200%를 찍고, 무배월에는 0%가 되어 사용자를 혼란스럽게 합니다.
- 연간 목표는 "올해 실제로 받을 예상 세후 배당금"이라는 핵심 메시지와 자연스럽게 연결됩니다.
- 헬스케어 앱의 "오늘 걸음 수 / 목표 10,000"과 같은 심리적 효과를 줍니다.
