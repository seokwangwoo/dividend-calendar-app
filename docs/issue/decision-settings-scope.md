# 설계 결정: 설정 화면 범위 및 계정 삭제 처리

## 결정일
2026-05-06

## 질문
1. 설정 화면의 구체적인 범위와 우선순위는?
2. "계정 삭제" 기능을 MVP에 포함할 것인가?
3. "기본 표시(세후/세전)" 설정의 영향 범위와 구현 방식은?

## 결정

### 1. 설정 화면 우선순위: Must로 격상, 범위는 최소화

MVP 설정 화면에 포함되는 항목:
- 연간 배당 목표 입력 (`users.annual_dividend_goal`)
- 이메일 알림 ON/OFF
- 기본 표시 설정 (세후 / 세전)
- 로그아웃

제외 항목:
- 계정 삭제 (Phase 1.5에서 구현)
- 통화 설정 (Phase 2에서 구현, MVP에서는 JPY 고정)

### 2. 계정 삭제: MVP에서 제외

- 설정 화면에서 "계정 삭제" 버튼을 숨깁니다.
- 사용자가 계정 삭제를 원할 경우 "고객 지원 이메일로 문의해주세요" 안내
- Phase 1.5에서 법무 검토 후 GDPR/개인정볼 완전 삭제 또는 soft delete 구현

### 3. 기본 표시 설정: DB 저장 + API 응답 포함

- `users` 테이블에 `default_display_basis` ('after_tax' | 'before_tax', DEFAULT 'after_tax') 추가
- 각 화면 API 응답에 `userPreference.default_display_basis` 포함
- 클라이언트는 해당 값을 참조하여 세후/세전 렌더링 전환
- 설정 변경 시 DB 업데이트, 다음 화면 로딩 시 반영

## 근거
- 목표 금액 입력과 알림 ON/OFF는 MVP 핵심 기능(홈 목표 달성률, 알림)과 직결되어 설정 화면이 필요합니다.
- 계정 삭제는 GDPR/개인정볼 대응이 필요하여 법무 검토와 별도 정책 수립이 선행되어야 합니다.
- 통화 설정은 MVP에서 JPY만 사용하므로 의미 없는 UI가 됩니다.
- DB 저장 방식이 가장 간단하고 일관성 있으며, 전역 상태 관리 없이도 모든 화면에서 동일한 기준을 적용할 수 있습니다.
