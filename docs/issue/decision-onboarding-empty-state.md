# 설계 결정: 신규 사용자 온보어딩 및 빈 상태(Empty State) UI

## 결정일
2026-05-06

## 질문
회원가입 직후 사용자는 보유 종목이 0개이므로 홈 화면의 핵심 가치("올해 예상 세후 배당")가 ¥0으로 표시됩니다. 온보어딩을 어떻게 구성하고, 빈 상태 UI를 어떻게 처리할 것인가?

## 결정
**별도의 `/onboarding` 슬라이드는 없습니다. 홈 화면 자체가 온보어딩 역할을 하며, 조걵뷰 렌더링으로 빈 상태를 처리합니다.**

### 상세

#### 1. 회원가입 후 흐름
```text
회원가입 → /app/home (즉시 이동, 온보어딩 슬라이드 없음)
```

#### 2. 홈 화면 조걵뷰 렌더링

**케이스 A: 보유 종목 0개**
```text
┌────────────────────────────┐
│ 홈                          │
│ 안녕하세요, Seo님            │
├────────────────────────────┤
│                            │
│   보유 종목을 추가하고       │
│   올해 배당을 확인핟보세요   │
│                            │
│   [+ 첫 종목 추가하기]       │
│                            │
├────────────────────────────┤
│ 홈 │ 포트폴리오 │ 캘린더 │ 알림 │ 설정 │
└────────────────────────────┘
```
- 기존 숫자 카드(올해 배당, 이번 달 입금, 목표 달성률) 전부 숨김
- 중앙에 큰 CTA 버튼만 표시
- 버튼 클릭 → `/app/stocks/search`

**케이스 B: 보유 종목 있음 + 목표 미설정 (`annual_dividend_goal IS NULL`)**
```text
올해 예상 세후 배당
¥384,000
세전 ¥480,000 / 예상 세금 ¥96,000
─────────────────────────
연간 목표를 설정핟면 진행 상황을
확인할 수 있습니다
[목표 설정하기]
```
- 배당 요약 카드는 정상 표시
- 목표 프로그레스 바 대신 "목표 설정" CTA 배너
- 배너 클릭 → 설정 화면 또는 목표 입력 모달

**케이스 C: 보유 종목 있음 + 목표 설정됨**
- 와이어프레임 그대로 표시 (정상 상태)

#### 3. 포트폴리오 탭 빈 상태
```text
┌────────────────────────────┐
│ 포트폴리오                  │
├────────────────────────────┤
│                            │
│   보유 중인 종목이 없습니다  │
│                            │
│   [+ 종목 추가하기]          │
│                            │
├────────────────────────────┤
│ 홈 │ 포트폴리오 │ 캘린더 │ 알림 │ 설정 │
└────────────────────────────┘
```

#### 4. 캘린더 탭 빈 상태
```text
배당 캘린더

보유 종목이 없어
입금 예정이 없습니다

[+ 종목 추가하기]
```

## 근거
- "첫 종목 추가 → 즉시 ¥15,000라는 숫자를 보는" 10초 내 경험이 가장 강력한 온보어딩입니다.
- 별도의 온보어딩 슬라이드는 사용자를 지체시키고 이탈률을 높입니다.
- 조걵뷰 렌더링으로 사용자는 가입 후 2초 만에 "뭘 해야 하는지"를 정확히 알 수 있습니다.
