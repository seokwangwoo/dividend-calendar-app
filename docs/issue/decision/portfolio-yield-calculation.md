# 설계 결정: 포트폴리오 수익률 계산 방식

> **상태: ✅ 해결됨** — `get_portfolio_summary()` RPC에서 세후 수익률 계산 및 레이블 반영 완료

## 결정일
2026-05-06

## 질문
와이어프레임의 포트폴리오 요약 카드에 있는 "평균 세후 수익률"은 어떤 방식으로 계산할 것인가?

## 결정
**레이블을 "평균 세후 수익률"에서 "포트폴리오 세후 수익률"로 변경하고, 계산 공식은 다음과 같습니다.**

```text
포트폴리오 세후 수익률 = 올해 예상 세후 배당 총액 / 포트폴리오 총 투자원금 × 100

포트폴리오 총 투자원금 = Σ(보유 수량 × 평균 취득가)
```

### 예시
| 종목 | 수량 | 평균 취득가 | 투자원금 | 세후 연간 배당 |
|------|------|------------|----------|---------------|
| KDDI | 100주 | ¥4,300 | ¥430,000 | ¥15,000 |
| JT | 100주 | ¥3,800 | ¥380,000 | ¥15,459 |
| **합계** | | | **¥810,000** | **¥30,459** |

```text
포트폴리오 세후 수익률 = 30,459 / 810,000 × 100 = 3.76%
```

## 근거
- 단순 평균((KDDI 수익률 + JT 수익률) / 2)은 투자 비중을 무시하여 실제 포트폴리오 성과를 왜곡합니다.
- "올해 예상 세후 배당 총액 / 총 투자원금"은 사용자의 **실제 자본 대비 실제 세후 현금흐름**을 보여주는 가장 정직한 지표입니다.
- 사용자는 "내 돈 810만 원으로 연간 3.76%의 세후 배당을 받는다"고 직관적으로 이해할 수 있습니다.
- 계산에 사용하는 주가는 **평균 취득가**이며, 현재 시장 주가(Stooq 전날 종가)는 사용하지 않습니다.
