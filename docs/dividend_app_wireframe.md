# 배당앱 와이어프레임 설계

## 핵심 요약

배당앱 와이어프레임은 **“홈에서 올해 세후 배당과 이번 달 입금 예정액을 바로 확인 → 포트폴리오에서 보유 종목 관리 → 캘린더에서 월별 입금 흐름 확인 → 알림으로 배당 변경/목표수익률 확인”** 흐름으로 설계하는 것이 좋습니다.

MVP 핵심은 복잡한 투자 분석이 아니라 **세후 배당금, 월별 현금흐름, 배당 일정, 알림**입니다.

---

# 1. 전체 앱 구조

## 하단 탭

```text
┌────────────────────────────┐
│          화면 콘텐츠         │
│                            │
│                            │
├────────────────────────────┤
│ 홈 │ 포트폴리오 │ 캘린더 │ 알림 │ 설정 │
└────────────────────────────┘
```

추천 탭은 5개입니다.

| 탭 | 역할 |
|---|---|
| 홈 | 올해/이번 달 세후 배당 요약 |
| 포트폴리오 | 보유 종목 관리 |
| 캘린더 | 월별 배당 입금 일정 |
| 알림 | 목표수익률, 배당 변경 알림 |
| 설정 | 계정, 표시 방식, 알림 설정 |

---

# 2. 홈 화면 와이어프레임

## 목적

앱을 열자마자 **“올해 실제로 얼마가 들어오는지”**를 보여줍니다.

```text
┌────────────────────────────┐
│ 홈                          │
│ 안녕하세요, Seo님            │
├────────────────────────────┤
│ 올해 예상 세후 배당          │
│ ┌────────────────────────┐ │
│ │ ¥384,000               │ │
│ │ 세전 ¥480,000           │ │
│ │ 예상 세금 ¥96,000        │ │
│ │ ─────────────────────── │ │
│ │ 연간 목표 ¥400,000 대비  │ │
│ │ 96%                     │ │
│ │ ██████████░             │ │
│ └────────────────────────┘ │
│                            │
│ 이번 달 예상 입금액          │
│ ┌────────────────────────┐ │
│ │ 6월                     │ │
│ │ ¥28,400                 │ │
│ │ [캘린더에서 보기]        │ │
│ └────────────────────────┘ │
│                            │
│ 다음 배당 예정              │
│ ┌────────────────────────┐ │
│ │ JT                     │ │
│ │ 6월 30일 예정            │ │
│ │ 세후 ¥15,459            │ │
│ │ 상태: 확정               │ │
│ └────────────────────────┘ │
│                            │
│ > 보유 종목 중 가장 가까운  │
│ > 배당 1걸만 표시합니다.    │
│ > 같은 종목을 여러 계좌에   │
│ > 보유하면 세후 금액을     │
│ > 합산하여 표시합니다.     │
│                            │
│ 최근 배당 변경              │
│ ┌────────────────────────┐ │
│ │ JT 배당 예상 변경         │ │
│ │ ¥194 → ¥200             │ │
│ │ 상태: 검수 완료           │ │
│ └────────────────────────┘ │
├────────────────────────────┤
│ 홈 │ 포트폴리오 │ 캘린더 │ 알림 │ 설정 │
└────────────────────────────┘
```

## 빈 상태 (Empty State)

보유 종목이 없을 때는 핵심 숫자 카드를 숨기고, 중앙에 "+ 첫 종목 추가하기" CTA만 표시합니다.

```text
┌────────────────────────────┐
│ 홈                          │
│ 안녕하세요, Seo님            │
├────────────────────────────┤
│                            │
│   보유 종목을 추가하고       │
│   올해 배당을 확인핟보세요   │
│                            │
│   [+ 첫 종목 추가하기]       │
│                            │
├────────────────────────────┤
│ 홈 │ 포트폴리오 │ 캘린더 │ 알림 │ 설정 │
└────────────────────────────┘
```

## 목표 미설정 상태

보유 종목이 있지만 `annual_dividend_goal`이 NULL이면, 배당 요약은 표시하고 목표 프로그레스 바 대신 "연간 목표를 설정핟하면 진행 상황을 확인할 수 있습니다" 배너를 표시합니다.

## 핵심 UX

홈에서는 **세후 금액을 가장 크게** 보여줘야 합니다.  
세전 금액은 보조 정보로 작게 보여주는 것이 좋습니다.

## 목적

일본 상장 주식을 검색하고 포트폴리오에 추가합니다.

```text
┌────────────────────────────┐
│ 종목 추가              취소 │
├────────────────────────────┤
│ 종목명 또는 코드 검색        │
│ ┌────────────────────────┐ │
│ │ KDDI 또는 9433 입력      │ │
│ └────────────────────────┘ │
│                            │
│ 검색 결과                   │
│ ┌────────────────────────┐ │
│ │ 9433 KDDI              │ │
│ │ 예상 배당수익률 3.7%     │ │
│ │ 지원 중                 │ │
│ └────────────────────────┘ │
│                            │
│ ┌────────────────────────┐ │
│ │ 2914 JT                │ │
│ │ 예상 배당수익률 4.5%     │ │
│ │ 지원 중                 │ │
│ └────────────────────────┘ │
│                            │
│ ┌────────────────────────┐ │
│ │ XXXX 미지원 종목         │ │
│ │ 현재 MVP 미지원          │ │
│ └────────────────────────┘ │
└────────────────────────────┘

## UX 포인트

MVP에서 지원하지 않는 종목은 숨기지 말고 **“현재 미지원”**으로 표시하는 것이 좋습니다.  
사용자는 “검색이 안 되는 오류”가 아니라 “아직 지원하지 않음”으로 이해할 수 있습니다.

│                            │

│ ┌────────────────────────┐ │

│ └────────────────────────┘ │

│ 홈 │ 포트폴리오 │ 캘린더 │ 알림 │ 설정 │
└────────────────────────────┘
```

## 보기 옵션

```text
[세후 / 세전]
[전체 / NISA / 특정계좌 / 일반계좌]
```

> MVP에서는 **월별 리스트 뷰**를 기본으로 제공합니다. 달력 그리드는 Phase 2로 미룹니다.

## 월별 집계 기준

- `payment_year` + `estimated_payment_month` 기준으로 해당 연도/월에 배당을 집계합니다.
- 사용자에게 보이는 "올해"는 달력연도(`payment_year`) 기준입니다.
- 날짜가 확정되지 않은 경우(下旬, 末日 등)는 텍스트로 표현하며, `payment_start_date`는 NULL로 둡니다.

## 빈 상태 (Empty State)

보유 종목이 없을 때:

```text
배당 캘린더

보유 종목이 없어
입금 예정이 없습니다

[+ 종목 추가하기]
```

## 상태 배지

| 상태 | 의미 |
|---|---|
| 예상 | 아직 확정되지 않은 예상 일정 |
| 확정 | 회사 공시 또는 데이터 검수 완료 |
| 지급 완료 | 실제 입금 완료 |
| 미정 | 지급월 또는 금액 미정 |
| 검수 완료 | 관리자 확인 완료 |

# 10. 알림 목록 화면 와이어프레임

## 목적

배당 변경, 목표수익률 도달, 데이터 업데이트를 확인합니다.

```text
┌────────────────────────────┐
│ 알림                        │
├────────────────────────────┤
│ [전체] [목표수익률] [배당변경]│
│                            │
│ 오늘                        │
│ ┌────────────────────────┐ │
│ │ 목표수익률 도달          │ │
│ │ KDDI 3.7%               │ │
│ │ 조건: 3.5% 이상          │ │
│ │ 10:30                   │ │
│ └────────────────────────┘ │
│                            │
│ 이번 주                     │
│ ┌────────────────────────┐ │
│ │ 배당 예상 변경           │ │
│ │ JT ¥194 → ¥200          │ │
│ │ 종류: 증배               │ │
│ │ 출처: TDnet              │ │
│ │ 상태: 검수 완료           │ │
│ └────────────────────────┘ │
├────────────────────────────┤
│ 홈 │ 포트폴리오 │ 캘린더 │ 알림 │ 설정 │
└────────────────────────────┘
```

## 알림 유형

| 유형 | 내용 |
|---|---|
| 목표수익률 도달 | 사용자가 설정한 조건 충족 |
| 증배 | 배당금 증가 |
| 감배 | 배당금 감소 |

# 최종 추천

이 앱은 **투자 분석 앱**보다 **배당 현금흐름 관리 앱**으로 보여야 합니다.

가장 중요한 첫 화면 메시지는 이것입니다.

```text
올해 실제로 받을 예상 세후 배당금
¥384,000
```

사용자가 이 숫자를 보고 바로 이해해야 합니다.

> “내가 올해 얼마를 받을 수 있는지”  
> “이번 달 얼마가 들어오는지”  
> “어떤 종목의 배당이 바뀌었는지”  
> “내 목표 수익률에 도달했는지”

이 4가지를 빠르게 확인하게 만드는 방향으로 와이어프레임을 잡는 것이 가장 좋습니다.
